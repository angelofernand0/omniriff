# Slow, then speed up

1. Use the TakeReport median interval to estimate the current pace. Do not invent a BPM if it is missing.
2. Ask for the same passage at about 70% of that pace for four repetitions, then return to the original pace for one recorded take. The player sets the pace; this skill does not silently change any rig control.
3. Keep effects unchanged by default. If a dry sound would clarify timing, propose bypass and wait for approval before calling `rig_control`.
4. Pass when the final take has fewer hesitations and no worse tempo stability than the original. Compare the actual numbers, and say when the data are too sparse to judge.
5. Give one concise cue about relaxing into the slower pulse, not a claim about technique that the reports cannot support.
